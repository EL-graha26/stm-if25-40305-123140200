## 🛠️ Perangkat & Lingkungan Pengembangan (Tech Stack)
* **Bahasa Pemrograman:** Python 3.12
* **Manajemen Environment:** `uv` / `venv`
* **Pustaka Utama (Libraries):**
  * `librosa` — Pemrosesan, pemuatan, dan analisis sinyal audio digital.
  * `opencv-python` — Pengolahan matriks piksel citra dan bingkai video digital.
  * `matplotlib` — Visualisasi data multi-domain (Waveform, FFT, Spektrogram).
  * `numpy` — Komputasi numerik dan manipulasi array multi-dimensi.
  * `scipy` — Perancangan filter digital (IIR/FIR) dan operasi DSP.
